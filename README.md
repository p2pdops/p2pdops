### What I'm building

**[zero-native](https://github.com/zero-native/zero-native)**: a mobile framework. You write screens in TSX and they compile to native Jetpack Compose and SwiftUI, with signed over-the-air updates. It runs a production app today: download size 14.9 MB to 6.4 MB, cold start 1,147 ms to about 505 ms on a low-end Android phone.

**[picots](https://github.com/p2pdops/picots)**: a very light desktop app framework on the operating system's own WebView.

Most of my commits are in private repos at [ZeroBill](https://zerobill.app): a payment gateway, Windows software in C++ and Rust, mobile apps and backend services on Kubernetes.
