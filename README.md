## Hi, I'm Pavan

I build whole products, from low-level Windows software up to the mobile app. I am the co-founder and CTO of [ZeroBill](https://zerobill.app): digital receipts, UPI payments and cashback for offline stores in India. I have been its only engineer for 5 years.

**[zero-native](https://github.com/zero-native/zero-native)** is a mobile framework I wrote. TSX screens compile to native Jetpack Compose and SwiftUI, with signed over-the-air updates. It runs the ZeroBill app in production: download size 14.9 MB to 6.4 MB, cold start 1,147 ms to about 505 ms on a low-end Android phone.

**[picots](https://github.com/p2pdops/picots)** is a very light desktop app framework on the operating system's own WebView.

**Payments (private):** ZeroBill's payment gateway, built directly on ICICI Bank's UPI and payout APIs.

**Windows (private):** software in C++, Win32 and Rust that turns a bill from any billing software into a digital receipt, with no setup in the store.
